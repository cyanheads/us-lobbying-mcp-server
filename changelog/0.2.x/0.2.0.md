# 0.2.0 — 2026-11-15

## Added

- **`skill://us-lobbying-guide/SKILL.md`** resource: a published agent skill covering identifier sources, accounting gates and workflows, shipped in the npm package, image and `.mcpb`.
- **`include`** input (`activity_descriptions`, `activity_lobbyists`) on `uslobbying_search_filings`, `uslobbying_get_client_profile` profile mode, `uslobbying_get_issue_spending` and `uslobbying_search_lobbyists` activity mode. ([#19](https://github.com/cyanheads/us-lobbying-mcp-server/issues/19))
- **`USLOBBYING_CLAMP_LIMITS`** (default `true`); `false` rejects over-cap `page_size`, `max_pages` and `row_limit` with `invalid_filter`. ([#19](https://github.com/cyanheads/us-lobbying-mcp-server/issues/19))
- **`uslobbying_get_issue_spending`** accepts `registrant_id` without `issue_code`, ledgering every selected filing of the registrant; a `clients` row set, keyed by client relationship `id`, joins the analytical row sets, profile mode included. ([#20](https://github.com/cyanheads/us-lobbying-mcp-server/issues/20))
- **`uslobbying_list_reference`** `states` topic. ([#18](https://github.com/cyanheads/us-lobbying-mcp-server/issues/18))
- **`uslobbying_search_foreign_agents`** `entity: "short_forms"` searches short-form registrants by name, and detail short forms report `termination_date`. ([#21](https://github.com/cyanheads/us-lobbying-mcp-server/issues/21))
- **FARA principal detail** reports `termination_date` from `TERMINATION_DATE`.

## Changed

- **`page_size` is the page boundary** ([#19](https://github.com/cyanheads/us-lobbying-mcp-server/issues/19)): a call returns whole records or rows, default and cap per unit below; the 24 KB byte budget is gone and upstream LDA requests always use `page_size=25`. Over-cap values clamp and are disclosed in `delivery_limits`.

  | Unit | Default | Cap |
  |:--|--:|--:|
  | `uslobbying_search_filings`, `uslobbying_get_contributions` | 10 | 25 |
  | `uslobbying_search_lobbyists` search, `uslobbying_get_client_profile` resolve | 25 | 25 |
  | `uslobbying_search_lobbyists` activity | 25 | 1,000 |
  | `uslobbying_get_client_profile` profile, `uslobbying_get_issue_spending` | 25 | 250 |
  | `uslobbying_search_foreign_agents` | 25 | 1,000 |
  | `uslobbying_dataframe_query` `row_limit` | 25 | 100, then the provider ceiling |
  | `uslobbying_list_reference` | fixed 125-entry windows | — |

- **Breaking: record-window inputs removed.** `record_handle`, `record_path`, `record_offset` and `record_limit` are gone from `uslobbying_search_filings`, `uslobbying_get_client_profile`, `uslobbying_get_issue_spending`, `uslobbying_search_lobbyists`, `uslobbying_get_contributions`, `uslobbying_search_foreign_agents` and `uslobbying_list_reference`. The strict schemas reject them as unknown arguments, including the old defaults a client may echo (`record_path: ""`, `record_offset: 0`, `record_limit: 25`). ([#19](https://github.com/cyanheads/us-lobbying-mcp-server/issues/19))
- **Breaking: record-window outputs removed.** `record_window`, `record_handles`, `records_deferred` and `retrieval_tool` are gone from the five LDA tools; `uslobbying_search_foreign_agents` loses `record_window`, `record_handles` and `records_deferred`; `uslobbying_list_reference` loses those four plus `delivery_limits`. Pages carry whole records instead. ([#19](https://github.com/cyanheads/us-lobbying-mcp-server/issues/19))
- **Breaking: activity `description` and `lobbyists` are omitted** unless `include` names `activity_descriptions` / `activity_lobbyists`, on `uslobbying_search_filings`, `uslobbying_get_client_profile`, `uslobbying_get_issue_spending` and `uslobbying_search_lobbyists`; a `filing_uuid` lookup includes both by default. ([#19](https://github.com/cyanheads/us-lobbying-mcp-server/issues/19))
- **Breaking: `uslobbying_dataframe_query` `row_order`** is `sql_result`, not `canonical_values`; windows follow the query's top-level `ORDER BY`. ([#17](https://github.com/cyanheads/us-lobbying-mcp-server/issues/17))
- **Breaking: `methodology.client_identity`** reads `relationship_records`, not `caller_selected_relationships`, on `uslobbying_get_client_profile` and `uslobbying_get_issue_spending`. ([#20](https://github.com/cyanheads/us-lobbying-mcp-server/issues/20))
- **Breaking: a continuation whose `page_size` differs from its first call's** now fails `cursor_invalid` on `uslobbying_get_client_profile` profile mode, `uslobbying_get_issue_spending`, `uslobbying_search_lobbyists` activity mode and `uslobbying_search_foreign_agents`, where the cap rose above 25. 0.1.2 clamped both values to 25 and accepted the call (26, then 25); omit `page_size` on a continuation or repeat it unchanged. ([#19](https://github.com/cyanheads/us-lobbying-mcp-server/issues/19))
- **Error reasons `result_too_large`** (`uslobbying_list_reference`, `uslobbying_search_foreign_agents`) **and `query_row_too_large`** (`uslobbying_dataframe_query`, `uslobbying_dataframe_describe`) are removed.
- **`uslobbying_dataframe_query`** reports a missing-file read as `sql_read_only` instead of `invalid_sql`, and admits `range()` and `generate_series()` (framework 0.13.22).
- **FARA detail short forms** omit a blank or null `first_name` / `last_name` instead of returning `null` or `""`.
- **Code-check rejections** (`invalid_filter`) name the `uslobbying_list_reference` topic that holds the codes; `uslobbying_search_filings` and `uslobbying_get_contributions` run them on the first call only, so a continuation never re-reads the constants.
- **Float-noise `page_size`, `max_pages` and `row_limit`** (`20.000000000000004`) round to integers.
- **The clamp-off rejection** carries a `Lower <field> to <cap> or less.` hint.
- **FARA name-search** query tokens are deduplicated; search cost stays linear in the query.
- **Descriptions** corrected, among them `row_sets` continuations and `specific_issues` not being an exact bill-number match.

## Fixed

- **1999–2007 semiannual reports** (`mid_year`, `year_end`) count in `uslobbying_get_client_profile` and `uslobbying_get_issue_spending` ledgers, which change for those years; a relationship-year that filed both grains keeps the statutory one and excludes the other as `off_cycle_period`, a new `selections[].exclusion_reason` that existing inputs can now return. An empty selection is reported per year. ([#16](https://github.com/cyanheads/us-lobbying-mcp-server/issues/16))
- **`uslobbying_search_filings` country and state codes** (`client_country`, `client_state`, `foreign_entity_country`) are checked against LDA constants and fail `invalid_filter` locally; a location-filtered first call on a cold constants cache waits for one constants request and fails with its upstream error if that request fails. ([#18](https://github.com/cyanheads/us-lobbying-mcp-server/issues/18))
- **FARA detail fields** that FARA's JSON sends as numbers now read as text; registration 5926's `documents` failed `source_schema_changed`.
