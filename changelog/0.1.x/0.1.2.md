# 0.1.2 — 2026-10-25

## Changed

- **Filing retrieval** accepts filing UUIDs, posting dates, reported-amount bounds, client location, foreign-entity and lobbyist-name filters; contribution amount bounds match individual items locally with exact cents. ([#10](https://github.com/cyanheads/us-lobbying-mcp-server/issues/10))
- **Analytical delivery** accepts opt-in `row_sets` while retaining complete acquisition, totals and SQL staging; dataset schemas appear on the first final window and its replay, with routing pointers on later windows. ([#11](https://github.com/cyanheads/us-lobbying-mcp-server/issues/11))
- **Response text** uses compact lossless JSON; output descriptions are shorter. ([#11](https://github.com/cyanheads/us-lobbying-mcp-server/issues/11), [#14](https://github.com/cyanheads/us-lobbying-mcp-server/issues/14))
- **Delivery controls** clamp positive page, acquisition, record and SQL row limits to their ceilings and disclose requested/effective values. ([#12](https://github.com/cyanheads/us-lobbying-mcp-server/issues/12))
- **Packaging and tooling** adopt framework scripts, development skills and Agent Plugins root manifests; registry metadata and documentation advertise the hosted endpoint.

## Fixed

- **FARA documents** follow the verified single registrant-documents redirect with pacing, deadline and source-URL preservation; unsupported redirects report nonretryable `source_schema_changed`. ([#7](https://github.com/cyanheads/us-lobbying-mcp-server/issues/7))
- **Client selection** identifies candidate `id` as the relationship filter and preserves the secondary `client_id`; bounded empty-partition notices distinguish zero source rows from excluded filings. ([#8](https://github.com/cyanheads/us-lobbying-mcp-server/issues/8))
- **Continuations** report changed scope as `cursor_invalid`; issue-spending retained windows and replay avoid source vocabulary requests, and missing state is distinguished from unreadable state. ([#6](https://github.com/cyanheads/us-lobbying-mcp-server/issues/6), [#13](https://github.com/cyanheads/us-lobbying-mcp-server/issues/13))
- **Coverage** sums the latest partition counts only when every partition count is known, preserving unknown totals and exact replay. ([#9](https://github.com/cyanheads/us-lobbying-mcp-server/issues/9))
- **MCPB startup** retains nested dependency runtime modules named `skills` while pruning dependency-root agent documentation and build-only files.
