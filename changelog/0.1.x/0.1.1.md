# 0.1.1 — 2026-10-25

## Added

- **LDA disclosures** — search filings, resolve client relationships, inspect filing-specific lobbyist activity, and retrieve complete LD-203 contribution reports with original and amended records.
- **Lobbying analysis** — select explicit relationships and years, retain amendment-selection evidence, and report exact income and expense ledgers separately; issue amounts remain overlapping whole-filing associations.
- **FARA records** — search official daily registrant and foreign-principal snapshots, then retrieve a registration's live principal, short-form, or document collection.
- **Complete delivery** — resumable acquisition, replayable cursors, retained-record retrieval, and matching structured and text responses preserve complete source records and provenance.
- **Local SQL** — optional DuckDB tables support schema inspection, read-only queries, complete result paging, and opt-in table deletion.
- **Client installation** — stdio and Streamable HTTP, npm and Docker installation, Claude Code and Codex plugins, and a Claude Desktop bundle with SQL disabled.

## Fixed

- **Retained text** fills the response byte budget while preserving Unicode offsets (#1).
- **Government entity identifiers** accept official source values (#2).
- **Reference vocabularies** deliver every matching entry through pinned result windows and retained-record handles (#3).
- **Source links** normalize rendered destinations while preserving original values in response data (#4).
